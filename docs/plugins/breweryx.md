# 🍾 Варка напитков | BreweryX

Плагин **BreweryX** добавляет на сервер интересную механика варить различные алкогольные и безалкогольные напитки в несколько этапов!

---

## 🧪 Как это работает?

Процесс создания напитка состоит из нескольких этапов:
1. **Варка в котле** — подготовка ингредиентов в кипящей воде.
2. **Дистилляция** — перегонка настоя в зельеварке.
3. **Выдержка в бочках** — выдерживание напитка в деревянных бочках из разных пород дерева.

!!! info "Официальный гайд"
    Подробный пошаговый гайд по рецептам и варке доступен на [Вики BreweryX](https://docs.breweryteam.dev/ru/docs/breweryx/gameplay/creating-brews/brewing). На нашем сервере используются стандартные рецепты.
