# Добро пожаловать 👋

Добро пожаловать в официальную базы знаний сервера **Hyperion**! Здесь вы найдёте всю необходимую информацию для комфортной игры.

---

## ℹ️ Основная информация

**Hyperion** — это ванильный Minecraft-сервер с добрым комьюнити и отзывчивой администрацией. Наш проект нацелен на создание уютной атмосферы, комфорта и позитивных эмоций.

На сервере установлены все необходимые плагины для интересной игры и удобной коммуникации между игроками.

---

## 🎮 Как начать играть?

!!! info "Параметры подключения"
    * **Версия сервера:** 1.20+ (26.2)
    * **Discord:** [Присоединиться к серверу](https://discord.gg/m8zM74NKXc)

### Инструкция по входу

1. Подайте заявку в нашем [Discord сервере](https://discord.gg/m8zM74NKXc).
2. После одобрения заявки зайдите на сервер Minecraft.
3. Привяжите свой Discord-аккаунт к боту, отправив ему полученный код из игры.
